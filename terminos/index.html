Términos de servicio

Última actualización: 20 de octubre de 2026

Este sitio es un blog personal. Aquí explico en qué condiciones puedes usar lo que publico y cómo funcionan las herramientas que conecto a otras plataformas. Lo que tiene que ver con tus datos está en la política de privacidad.

1. Quién está detrás

Ángel García, analista de datos, desde Lima, Perú. No hay una empresa detrás. Para cualquier consulta, escríbeme a angelgarciadatablog@gmail.com.

2. Cómo puedes usar el contenido

  • Leer y compartir: puedes leer todo el contenido y compartirlo con un enlace a la página original.
  • Código de ejemplo: los comandos y fragmentos de código que publico están para que los uses en tus propios proyectos, personales o de trabajo.
  • Lo que no: copiar artículos, videos o materiales del curso completos para publicarlos como propios o venderlos.

3. Sin garantías

Escribo lo que pruebo y verifico, pero las herramientas y las plataformas cambian. El contenido y el código se ofrecen tal cual: revisa lo que ejecutas, sobre todo si borra, modifica o envía algo, y pruébalo primero en un entorno donde un error no cause daños. No me hago responsable de las pérdidas o problemas que resulten de aplicarlo.

4. Cursos y servicios

Si accedes a un servicio concreto, como la base de datos del curso de SQL o una asesoría, se aplican además sus propias condiciones, que te explico al darte el acceso. El acceso es personal: no compartas tus credenciales ni intentes usar la base de datos para algo distinto de practicar. Puedo desactivar un acceso que se use de forma indebida.

5. Mis herramientas conectadas a otras plataformas

Tengo aplicaciones registradas en algunas plataformas (por ejemplo, Google o TikTok) para automatizar tareas con mis propias cuentas, como leer la lista de mis videos publicados para enlazarlos en este blog.

  • Quién las usa: solo yo. No están abiertas al público y nunca te pedirán que inicies sesión con tu cuenta.
  • Qué hacen: leen o mueven información de mis cuentas. No publican en nombre de nadie más.
  • Reglas de cada plataforma: su uso respeta los términos de servicio y las políticas para desarrolladores de cada plataforma.

6. Enlaces a otros sitios

Enlazo a documentación oficial y a otras páginas. No controlo su contenido y cada una tiene sus propias condiciones.

7. Cambios en estos términos

Si cambio algo, actualizo la fecha del principio.
