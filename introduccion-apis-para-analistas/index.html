1. Qué es una API

Una API es un contrato entre dos sistemas: un conjunto de reglas sobre qué se puede pedir o hacer, cómo hay que pedirlo y qué se recibe a cambio. No es un archivo ni un servidor.

En ese contrato hay dos partes:

  • Quien pide: una persona, un script o una aplicación.
  • La plataforma que atiende: escribe las reglas y las publica en la documentación de la API.

Si la petición cumple las reglas, la plataforma responde con datos o haciendo algo (guardar, publicar, enviar, borrar). Si no, responde con un error.

Las APIs que no ves y las que puedes usar

Detrás de casi cada botón de una aplicación hay una llamada a una API: el "me gusta" lo registra una API, la foto que publicas la guarda otra. Esas APIs las definió quien construyó la aplicación, y su razón de ser principal es comunicar el frontend con el backend.

Algunas plataformas, además, abren una parte de sus APIs para que armes tus propias peticiones sin pasar por sus botones. Esa parte es más pequeña, y sacar datos para analizarlos es solo uno de sus usos. Aun así, para un analista es una de las mejores formas de conseguir datos de manera automática.

Quién te da el acceso

Datos Dónde viven Quién te da el acceso
De una empresa SAP, Oracle, Azure, Google Cloud, AWS Alguien de adentro: el área de sistemas o de desarrollo

Nota: para saber si una plataforma tiene API = buscar su sección para desarrolladores.

2. Con qué APIs vamos a practicar

APIs públicas: no piden credencial

Con ellas se deja atrás el CSV y aparece el formato en el que responden casi todas las APIs: JSON. Lo exploraremos junto con lo básico de Python.

API Qué datos da

Antes de pedir los datos, tienes que demostrar que eres tú.

Más adelante: crear y modificar

Las APIs no son solo para consultar. También permiten crear o modificar: crear páginas en Notion, publicar en LinkedIn o modificar un repositorio en GitHub. Ese es el mundo del desarrollador; la serie empieza por el del analista, que recibe datos.

3. Desde dónde se hace la petición

Opción Ventaja Limitación
Terminal (Mac) / PowerShell (Windows) Ya viene instalada La respuesta llega amontonada y los comandos cambian entre sistemas
Postman Respuesta ordenada, sin código; ideal para explorar Hay que descargarla y no automatiza el resto del trabajo
Python Pide, limpia, guarda y automatiza Requiere instalar y aprender lo básico

Un ejemplo de por qué la terminal confunde:

curl https://pokeapi.co/api/v2/pokemon/pikachu
  • Mac: curl es el programa curl y devuelve el JSON.
  • Windows PowerShell 5.1: curl es un alias de Invoke-WebRequest. Muestra una advertencia de seguridad y luego una tabla con el JSON cortado. El curl real se llama con curl.exe.
